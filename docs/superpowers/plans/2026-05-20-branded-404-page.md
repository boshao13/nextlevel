# Branded 404 Page Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the unstyled catch-all 404 with a branded, on-brand-witty 404 page, and make genuinely-missing URLs return a real HTTP 404 status.

**Architecture:** A new presentational `src/NotFound.jsx` styled-components component (mirroring `src/ThankYou.jsx`) renders inside the existing `PublicLayout`. It is wired to both the `path="*"` catch-all and an explicit `path="/404"` route. `/404` and `/snake` are added to the puppeteer prerender allow-list so every valid route has a static file; nginx then uses `try_files … =404` + `error_page 404 /404/index.html` to return a true 404 status for missing URLs.

**Tech Stack:** React 18 (Create React App), react-router-dom v6, styled-components v6, react-helmet, puppeteer prerender (`scripts/prerender.js`), nginx on EC2.

**Spec:** `docs/superpowers/specs/2026-05-20-branded-404-page-design.md`

**Note on workflow:** This project works on `main` with `./deploy.sh` (build + prerender + rsync to EC2). No worktree. Tests run via `npx react-scripts test` (Jest + React Testing Library ship with CRA; this adds the repo's first test file).

- [ ] **Step 2: Edit `location /` in the main www server block**

In `/etc/nginx/sites-enabled/default`, inside `server { server_name www.nextlevelepoxynm.com; … }`, the `location / { … }` block currently contains:

preserved. Do NOT touch the `location ^~ /admin` block (it keeps its own
`try_files … /index.html` SPA fallback and stays 200). Do NOT touch the
existing `location = /garage-makeover` 301 block.
